# 06 - Dati usati dall'app (Non Tecnico)

## Categorie di dati
- Conti
- Categorie di spesa/entrata
- Movimenti
- Trasferimenti
- Indicatori dashboard

## Perché è utile
Un lessico dati condiviso evita ambiguità tra funzionalità e report.

## Impatto
Riduce errori di interpretazione e migliora la qualità dei risultati mostrati.
