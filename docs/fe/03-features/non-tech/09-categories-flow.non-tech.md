# 09 - Flusso categorie (Non Tecnico)

## Obiettivo
Organizzare i movimenti per tipologia, così da migliorare lettura e controllo delle spese.

## Dove si trova
La gestione delle categorie è una scheda della pagina "Impostazioni" (scheda "Categorie"), non più una pagina a sé stante. L'analisi dell'andamento nel tempo per categoria si trova invece nella home, nella sezione "Patrimonio".

## Azioni utente
- Cercare una categoria per nome.
- Creare una nuova categoria (nome, descrizione, tag, priorità).
- Modificare una categoria esistente.
- Eliminare una categoria (non è possibile eliminare la categoria di default; le transazioni collegate a una categoria eliminata vengono riassegnate alla categoria di default).
